Cara kerjaHow it works

Aplikasi backup tidak masuk sebagai akun pengguna. Ia memakai identitas sebuah bot (aplikasi Lark) untuk dua hal: mengunggah file hasil backup ke Lark Drive, dan mengirim laporan ke chat grup.The backup application does not sign in as a user. It uses the identity of a bot (a Lark app) for two things: uploading backup files to Lark Drive, and sending reports to a group chat.

Bot tidak bisa diundang langsung ke sebuah folder seperti pengguna biasa. Cara yang berlaku di Lark adalah memasukkan bot ke sebuah grup, lalu membagikan folder ke grup tersebut. Dengan begitu bot ikut mendapat akses ke folder.A bot cannot be invited to a folder directly like a regular user. The approach that works in Lark is to add the bot to a group, then share the folder with that group. The bot then inherits access to the folder.

01

Membuat botCreating the bot

Lakukan dengan akun yang punya akses ke Developer Console. Jika perusahaan Anda memakai Feishu, ganti alamat dengan open.feishu.cn.Use an account that has access to the Developer Console. If your company uses Feishu, replace the address with open.feishu.cn.

  1. Buka open.larksuite.com/app dan masuk dengan akun Lark perusahaan.Open open.larksuite.com/app and sign in with your company Lark account.
  2. Klik Create custom app.Click Create custom app.
  3. Isi nama aplikasi (misalnya SQL Backup Bot), deskripsi singkat, dan ikon bila perlu, lalu klik Create.Enter the app name (for example SQL Backup Bot), a short description, and an icon if needed, then click Create.
  4. Di menu Credentials & Basic Info, salin App ID dan App Secret. Simpan keduanya, nanti diisi di aplikasi backup.Under Credentials & Basic Info, copy the App ID and App Secret. Keep both, you will enter them in the backup app later.
  5. Buka menu Add features (kadang tampil sebagai App Capabilities), cari Bot, lalu klik Add. Tanpa langkah ini bot tidak bisa dimasukkan ke grup dan tidak bisa mengirim pesan.Open Add features (sometimes shown as App Capabilities), find Bot, then click Add. Without this step the bot cannot be added to a group and cannot send messages.
Jaga App SecretProtect the App Secret

Siapa pun yang memegang App ID dan App Secret bisa bertindak sebagai bot ini. Jangan dibagikan lewat chat umum atau disimpan di repositori.Anyone who holds the App ID and App Secret can act as this bot. Do not share them in public chats or store them in a repository.

Tampilan nama permission di Developer Console dapat berubah antar versi. Jika kode di tabel tidak muncul persis, cari berdasarkan kata kunci (upload, drive, send message) dan pilih permission yang deskripsinya sama. Jika perusahaan ingin hak yang lebih sempit, permission khusus upload file (drive:file:upload) bisa dicoba menggantikan drive:drive.Permission names in the Developer Console can change between versions. If a code in the table does not appear exactly, search by keyword (upload, drive, send message) and pick the permission with the same description. If your company wants narrower access, the file-upload-only permission (drive:file:upload) can be tried in place of drive:drive.

03

Publish aplikasiPublishing the app

Permission dan bot baru berlaku setelah aplikasi dirilis. Tahap ini harus diulang setiap kali Anda menambah atau mengubah permission.Permissions and the bot only take effect after the app is released. Repeat this step every time you add or change permissions.

  1. Buka menu Version Management & Release lalu klik Create a version.Open Version Management & Release, then click Create a version.
  2. Isi nomor versi (misalnya 1.0.0) dan catatan rilis. Pada Availability, pilih pengguna atau seluruh anggota yang boleh melihat bot. Anggota grup yang akan berisi bot sebaiknya termasuk.Enter a version number (for example 1.0.0) and release notes. Under Availability, choose the users or all members who may see the bot. Members of the group that will contain the bot should be included.
  3. Klik Save, lalu Submit for release.Click Save, then Submit for release.
  4. Admin Lark menyetujui permintaan di Lark Admin Console. Jika Anda sendiri adalah admin, setujui langsung di sana. Status aplikasi berubah menjadi Released setelah disetujui.A Lark admin approves the request in the Lark Admin Console. If you are the admin, approve it there yourself. The app status changes to Released once approved.
04

Menambahkan bot ke grupAdding the bot to a group

Siapkan grup Lark yang akan menjadi perantara akses. Grup ini boleh sama dengan grup tempat laporan backup dikirim, boleh juga grup khusus.Prepare the Lark group that will act as the access intermediary. It can be the same group that receives backup reports, or a dedicated group.

  1. Buka grup di Lark, klik ikon Settings di pojok kanan atas.Open the group in Lark and click the Settings icon at the top right.
  2. Pilih Bots, lalu Add Bot.Choose Bots, then Add Bot.
  3. Cari nama aplikasi yang Anda buat (misalnya SQL Backup Bot) dan klik Add.Search for the app name you created (for example SQL Backup Bot) and click Add.
Bot tidak muncul di pencarian?Bot does not appear in search?

Artinya aplikasi belum berstatus Released, atau akun Anda tidak termasuk dalam availability yang dipilih di langkah 3.This means the app is not yet Released, or your account is not included in the availability chosen in step 3.

05

Membagikan folder ke grupSharing the folder with the group

Folder tujuan backup harus dibagikan ke grup yang berisi bot. Bot mewarisi akses grup tersebut.The backup destination folder must be shared with the group that contains the bot. The bot inherits that group's access.

  1. Buka Drive di Lark dan buat folder tujuan, misalnya satu folder per database atau satu folder untuk semua backup.Open Drive in Lark and create the destination folder, for example one folder per database or one folder for all backups.
  2. Klik kanan folder, pilih Share.Right-click the folder and choose Share.
  3. Cari nama grup yang sudah berisi bot, lalu tambahkan sebagai collaborator.Search for the group that already contains the bot, then add it as a collaborator.
  4. Atur izin menjadi Can edit. Izin Can view tidak cukup karena bot perlu menulis file ke folder.Set the permission to Can edit. Can view is not enough because the bot needs to write files into the folder.
  5. Klik Send atau Confirm.Click Send or Confirm.

Jika backup beberapa database dipisah ke folder berbeda, bagikan setiap folder tersebut ke grup yang sama. Subfolder di dalam folder yang sudah dibagikan ikut mewarisi izinnya.If backups for several databases go to different folders, share each of those folders with the same group. Subfolders inside a shared folder inherit its permissions.

AlternatifAlternative

Jika folder sudah dibagikan ke grup bawaan "All Members" dengan izin edit, langkah ini bisa dilewati. Pertimbangkan dulu apakah semua anggota perusahaan memang boleh mengubah file backup.If the folder is already shared with the built-in "All Members" group with edit permission, this step can be skipped. First consider whether every member of the company should really be able to modify backup files.

Mengambil ID dan domainGetting the IDs and domain

Folder ID

Buka folder tujuan di browser. Folder ID adalah bagian URL setelah /folder/.Open the destination folder in your browser. The Folder ID is the part of the URL after /folder/.

https://namaperusahaan.jp.larksuite.com/drive/folder/fldjzXXXXXXXXXXXXXXXXXXXXXX

Drive domain

Bagian host dari URL yang sama, tanpa https:// dan tanpa garis miring di akhir. Pada contoh di atas: namaperusahaan.jp.larksuite.com. Domain ini dipakai untuk membentuk tautan file yang dikirim di notifikasi.The host part of the same URL, without https:// and without a trailing slash. In the example above: namaperusahaan.jp.larksuite.com. This domain is used to build the file links sent in notifications.

Chat ID grupGroup Chat ID

Chat ID berawalan oc_ dan tidak ditampilkan di tampilan grup. Cara mengambilnya:The Chat ID starts with oc_ and is not displayed in the group view. To get it:

  1. Pastikan permission im:chat:readonly sudah ditambahkan dan versi aplikasi sudah dirilis ulang.Make sure the im:chat:readonly permission has been added and the app version has been released again.
  2. Buka API Explorer, pilih aplikasi Anda, dan cari Get chat list.Open API Explorer, select your app, and search for Get chat list.
  3. Pilih tipe token tenant_access_token, lalu klik Try it out.Choose the token type tenant_access_token, then click Try it out.
  4. Pada hasil, cari grup berdasarkan nama dan salin nilai chat_id. Daftar ini hanya memuat grup yang sudah berisi bot.In the result, find the group by name and copy the chat_id value. This list only includes groups that already contain the bot.

KeamananSecurity

  • Berikan permission seperlunya saja. Cabut im:chat:readonly setelah Chat ID didapat.Grant only the permissions you need. Remove im:chat:readonly once you have the Chat ID.
  • Gunakan grup khusus untuk akses folder backup dan batasi siapa yang menjadi anggotanya, karena semua anggota grup ikut mendapat izin edit pada folder tersebut.Use a dedicated group for backup folder access and limit its membership, because every group member also gets edit permission on the folder.
  • Jika App Secret bocor, buat ulang lewat Credentials & Basic Info, lalu perbarui di menu Setting aplikasi backup.If the App Secret leaks, regenerate it under Credentials & Basic Info, then update it in the backup app's Setting menu.
  • Batasi akses ke folder aplikasi backup di komputer, karena App Secret tersimpan di berkas konfigurasi lokal.Restrict access to the backup app folder on the computer, because the App Secret is stored in a local configuration file.

Butuh bantuan atau ingin membeli license key aplikasi? Hubungi customerservice@ptga.my.id.Need help or want to buy an app license key? Contact customerservice@ptga.my.id.

Disclaimer dan peringatan anti-virusDisclaimer and antivirus warnings

Aplikasi ini bukan virus atau malware.This application is not a virus or malware.

Sebagian program anti-virus atau Windows Defender dapat memberikan peringatan false positive (deteksi palsu) atau memblokir file FTP-And-Lark-Backup-SQL.exe. Hal ini dapat terjadi karena aplikasi belum ditandatangani dengan digital certificate (code signing) komersial, serta adanya fitur keamanan internal yang memproteksi lisensi perangkat.Some antivirus programs or Windows Defender may raise a false positive warning or block the file FTP-And-Lark-Backup-SQL.exe. This can happen because the application has not been signed with a commercial digital certificate (code signing), and because of an internal security feature that protects the device license.

Jika aplikasi terdeteksi sebagai ancaman, atau file executable terhapus atau diblokir secara otomatis, ikuti langkah berikut:If the application is flagged as a threat, or the executable is deleted or blocked automatically, follow these steps:

  1. Pulihkan file dari karantina. Buka menu anti-virus atau Windows Defender, cari menu Quarantine (Karantina), pilih file aplikasi ini, lalu lakukan Restore (Pulihkan).Restore the file from quarantine. Open your antivirus or Windows Defender, find the Quarantine menu, select this application's file, then choose Restore.
  2. Tambahkan pengecualian (exclusion). Tambahkan folder aplikasi FTP & LARK Backup SQL ke daftar Exclusion atau Allowed Threats di anti-virus Anda, supaya backup otomatis dan akses file lisensi tidak terganggu di kemudian hari.Add an exclusion. Add the application folder FTP & LARK Backup SQL to the Exclusion or Allowed Threats list in your antivirus, so automatic backups and license file access are not interrupted later.
