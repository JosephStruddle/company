00

Cara kerja

Aplikasi backup tidak masuk sebagai akun pengguna. Ia memakai identitas sebuah bot (aplikasi Lark) untuk dua hal: mengunggah file hasil backup ke Lark Drive, dan mengirim laporan ke chat grup.

Bot tidak bisa diundang langsung ke sebuah folder seperti pengguna biasa. Cara yang berlaku di Lark adalah memasukkan bot ke sebuah grup, lalu membagikan folder ke grup tersebut. Dengan begitu bot ikut mendapat akses ke folder.

Rilis terbaru (v1.1) tersedia di halaman Releases GitHub. Unduh arsipnya, ekstrak, lalu jalankan App.exe. Panduan di bawah dikerjakan sebelum aplikasi dipakai untuk backup pertama.

01

Membuat bot

Lakukan dengan akun yang punya akses ke Developer Console. Jika perusahaan Anda memakai Feishu, ganti alamat dengan open.feishu.cn.

  1. Buka open.larksuite.com/app dan masuk dengan akun Lark perusahaan.
  2. Klik Create custom app.
  3. Isi nama aplikasi (misalnya SQL Backup Bot), deskripsi singkat, dan ikon bila perlu, lalu klik Create.
  4. Di menu Credentials & Basic Info, salin App ID dan App Secret. Simpan keduanya, nanti diisi di aplikasi backup.
  5. Buka menu Add features (kadang tampil sebagai App Capabilities), cari Bot, lalu klik Add. Tanpa langkah ini bot tidak bisa dimasukkan ke grup dan tidak bisa mengirim pesan.
Jaga App Secret

Siapa pun yang memegang App ID dan App Secret bisa bertindak sebagai bot ini. Jangan dibagikan lewat chat umum atau disimpan di repositori.

02

Permission bot

Buka menu Permissions & Scopes, lalu klik Add permission scopes to app. Ketik nama permission di kolom pencarian, centang, lalu konfirmasi.

PermissionDipakai untukWajib
drive:drive
View, comment, edit and manage all files in Drive		Mengunggah file backup ke folder Lark Drive (endpoint upload file).Ya
im:message:send_as_bot
Send messages as an app		Mengirim laporan hasil backup ke grup.Ya
im:chat:readonly
View group information		Hanya untuk mencari Chat ID lewat API Explorer (langkah 7). Boleh dicabut setelahnya.Opsional
Nama bisa berbeda

Tampilan nama permission di Developer Console dapat berubah antar versi. Jika kode di tabel tidak muncul persis, cari berdasarkan kata kunci (upload, drive, send message) dan pilih permission yang deskripsinya sama. Jika perusahaan ingin hak yang lebih sempit, permission khusus upload file (drive:file:upload) bisa dicoba menggantikan drive:drive.

03

Publish aplikasi

Permission dan bot baru berlaku setelah aplikasi dirilis. Tahap ini harus diulang setiap kali Anda menambah atau mengubah permission.

  1. Buka menu Version Management & Release lalu klik Create a version.
  2. Isi nomor versi (misalnya 1.0.0) dan catatan rilis. Pada Availability, pilih pengguna atau seluruh anggota yang boleh melihat bot. Anggota grup yang akan berisi bot sebaiknya termasuk.
  3. Klik Save, lalu Submit for release.
  4. Admin Lark menyetujui permintaan di Lark Admin Console. Jika Anda sendiri adalah admin, setujui langsung di sana. Status aplikasi berubah menjadi Released setelah disetujui.
04

Menambahkan bot ke grup

Siapkan grup Lark yang akan menjadi perantara akses. Grup ini boleh sama dengan grup tempat laporan backup dikirim, boleh juga grup khusus.

  1. Buka grup di Lark, klik ikon Settings di pojok kanan atas.
  2. Pilih Bots, lalu Add Bot.
  3. Cari nama aplikasi yang Anda buat (misalnya SQL Backup Bot) dan klik Add.
Bot tidak muncul di pencarian?

Artinya aplikasi belum berstatus Released, atau akun Anda tidak termasuk dalam availability yang dipilih di langkah 3.

05

Membagikan folder ke grup

Folder tujuan backup harus dibagikan ke grup yang berisi bot. Bot mewarisi akses grup tersebut.

  1. Buka Drive di Lark dan buat folder tujuan, misalnya satu folder per database atau satu folder untuk semua backup.
  2. Klik kanan folder, pilih Share.
  3. Cari nama grup yang sudah berisi bot, lalu tambahkan sebagai collaborator.
  4. Atur izin menjadi Can edit. Izin Can view tidak cukup karena bot perlu menulis file ke folder.
  5. Klik Send atau Confirm.

Jika backup beberapa database dipisah ke folder berbeda, bagikan setiap folder tersebut ke grup yang sama. Subfolder di dalam folder yang sudah dibagikan ikut mewarisi izinnya.

Alternatif

Jika folder sudah dibagikan ke grup bawaan "All Members" dengan izin edit, langkah ini bisa dilewati. Pertimbangkan dulu apakah semua anggota perusahaan memang boleh mengubah file backup.

06

Mengambil ID dan domain

Folder ID

Buka folder tujuan di browser. Folder ID adalah bagian URL setelah /folder/.

https://namaperusahaan.jp.larksuite.com/drive/folder/fldjzXXXXXXXXXXXXXXXXXXXXXX

Drive domain

Bagian host dari URL yang sama, tanpa https:// dan tanpa garis miring di akhir. Pada contoh di atas: namaperusahaan.jp.larksuite.com. Domain ini dipakai untuk membentuk tautan file yang dikirim di notifikasi.

Chat ID grup

Chat ID berawalan oc_ dan tidak ditampilkan di tampilan grup. Cara mengambilnya:

  1. Pastikan permission im:chat:readonly sudah ditambahkan dan versi aplikasi sudah dirilis ulang.
  2. Buka API Explorer, pilih aplikasi Anda, dan cari Get chat list.
  3. Pilih tipe token tenant_access_token, lalu klik Try it out.
  4. Pada hasil, cari grup berdasarkan nama dan salin nilai chat_id. Daftar ini hanya memuat grup yang sudah berisi bot.

Menu + Tambah Database

Isi Folder Lark ID dengan folder ID dari langkah 6. Setiap database boleh memakai folder yang berbeda.

Uji koneksi dan backup pertama

  1. Di halaman utama, klik Cek ulang koneksi. Status Lark harus berubah menjadi terhubung.
  2. Klik Run Backup, pilih satu database kecil dan tujuan Lark Drive.
  3. Setelah selesai, periksa dua hal: file muncul di folder Lark, dan laporan masuk ke grup.
08

Pemecahan masalah

GejalaPenyebab yang umum dan solusi
Gagal mengambil token / koneksi Lark gagalApp ID atau App secret salah, ada spasi tersisa saat menyalin, atau API base URL tidak sesuai (Lark dan Feishu berbeda).
Upload ditolak (permission / access denied)Folder belum dibagikan ke grup yang berisi bot, izin hanya Can view, atau permission drive:drive belum dirilis. Cek langkah 3 sampai 5.
Upload gagal karena folder tidak ditemukanFolder ID salah salin, atau folder berada di ruang yang tidak terjangkau grup tersebut.
Pesan laporan tidak masuk ke grupBot belum ditambahkan ke grup, Chat ID salah, atau permission im:message:send_as_bot belum dirilis.
File terunggah tetapi tautan tidak bisa dibukaDrive domain salah. Samakan dengan host URL yang Anda pakai saat membuka Lark Drive di browser.
Sudah menambah permission tapi tetap ditolakPerubahan permission baru aktif setelah membuat versi baru dan disetujui admin. Ulangi langkah 3.
Bot tidak bisa ditemukan saat Add BotAplikasi belum berstatus Released atau kemampuan Bot belum ditambahkan (langkah 1 butir 5).

Untuk detail kegagalan, buka folder logs di sebelah App.exe, atau klik item status di aplikasi untuk melihat log proses tersebut.

09

Keamanan

  • Berikan permission seperlunya saja. Cabut im:chat:readonly setelah Chat ID didapat.
  • Gunakan grup khusus untuk akses folder backup dan batasi siapa yang menjadi anggotanya, karena semua anggota grup ikut mendapat izin edit pada folder tersebut.
  • Jika App Secret bocor, buat ulang lewat Credentials & Basic Info, lalu perbarui di menu Setting aplikasi backup.
  • Batasi akses ke folder aplikasi backup di komputer, karena App Secret tersimpan di berkas konfigurasi lokal.
